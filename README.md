# مركز تتبع الطلب ميلانو OTC

## Milano OTC Order Tracking Platform

### المقدمة

منصة تتبع الطلبات. تتيح للمستخدمين معرفة حالة طلباتهم من خلال رقم التتبع.

### الميزات

- **تتبع الشحنات**: البحث عن حالة الشحنة برقم التتبع
- **لوحة تحكم**: إدارة الطلبات وإضافة أرقام التتبع
- **دعم RTL**: واجهة عربية بالكامل
- **تصميم متجاوب**: يعمل على جميع الأجهزة
- **تخزين محلي**: حفظ البيانات في المتصفح

### التثبيت

1. تثبيت المتطلبات:
```bash
npm install
```

2. تشغيل السيرفر:
```bash
npm start
```

3. فتح المتصفح على:
- الصفحة الرئيسية: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

### بيانات الدخول التجريبية

- **اسم المستخدم**: admin
- **كلمة المرور**: 123456

### كيفية الاستخدام

#### للمستخدمين:
1. افتح الصفحة الرئيسية
2. أدخل رقم التتبع (مثال: EE123456789EG)
3. اضغط على "تتبع"
4. ستظهر تفاصيل الشحنة

#### للأدمن:
1. سجل الدخول ببيانات التجريبية
2. أضف طلباً جديداً مع رقم التتبع
3. يمكنك تعديل أو حذف الطلبات
4. يمكنك بحث وتصفية الطلبات

### تحديث البيانات يدوياً

يمكن للأدمن تحديث بيانات الطلبات من خلال:
1. تسجيل الدخول للوحة التحكم
2. العثور على الطلب المطلوب
3. تعديل حالة الطلب
4. حفظ التعديلات

### ملاحظات تقنية

- البيانات محفوظة في `localStorage` للمتصفح
- للحفاظ على البيانات بين الأجهزة، يُنصح بقاعدة بيانات خارجية
- يُنصح بتأمين لوحة التحكم بقاعدة بيانات حقيقية
